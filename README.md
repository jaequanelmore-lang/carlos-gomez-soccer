# Carlos Gomez Athlete Website

A responsive, accessible, SEO/AEO-conscious static soccer player portfolio starter.

## Pages
- `index.html` — homepage, biography, stat snapshot, athlete facts
- `media.html` — highlight reel and photo gallery placeholders
- `contact.html` — contact details and email CTA placeholder

## Run locally
Open `index.html` in a browser. No build tools are required.

## Before publishing
1. Confirm Carlos's position, club/team, season details and biography. Current confirmed details: Class of 2027, Royal Live Oaks Academy, 5'10", right-footed.
2. Add verified season statistics, an approved player photo and gallery images. Position is currently listed as “To be determined”; club, GPA and academic interests have not been provided.
3. Add a verified recruiting email and, if appropriate, parent/guardian or school coach contact. The site currently displays no email address.
4. Update the canonical website URL in the JSON-LD and add a canonical link once the domain is known.
5. Add image alt text describing the actual image; compress images to WebP/AVIF.
6. Add Carlos’s verified highlight-film link and embed it accessibly. The film has not yet been provided.
7. Add real social profile links and Open Graph image when approved.
8. Verify all stats and obtain permission for photos/videos before publishing.

## GitHub Pages
Create a repository named `carlos-gomez-athlete-site`, upload these files to the repository root, then enable Pages from the `main` branch and `/ (root)` in repository Settings > Pages.
